Живые курсы в рабочем `data/` не коммитятся и могут устареть к моменту просмотра.
Выполните `update-rates --source coingecko`, либо задайте фиатный ключ и выполните
`update-rates`. Демонстрация в docs использует отдельные учебные ответы API и
не изменяет рабочие кошельки.

Все автоматические тесты работают без сети. Покрытие 92% не означает проверку
каждого возможного поведения: в частности, POSIX-ветка файловой блокировки здесь
не исполнялась, а доступность внешних API меняется со временем.

После ошибок Windows, обнаруженных в дополнительных проверках, исправлены:
чтение заблокированного диапазона до получения lock и открытые log handlers при
удалении временной папки демонстрации. Повторные проверки проходят.

```powershell
uv run ruff check .
uv run ruff format --check .

uv run python -m scripts.demo
uv build
git status --short
git log --oneline
```
