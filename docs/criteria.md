Дополнительно: @confirm_action на выходе, ttl_cache через замыкание,
отдельный планировщик, журнал сделок, межпроцессная блокировка и восстановление
согласованности нескольких JSON после прерывания процесса.

Пустые *.example.json отслеживаются Git; реальные JSON создаются автоматически.
В ТЗ есть противоречия buy и ориентации фиатного курса — принятые решения подробно
объяснены в README. Источники в демо явно помечены DEMO; запись воспроизводима
без ключа и не выдаётся за доказательство живого HTTP-запроса.
